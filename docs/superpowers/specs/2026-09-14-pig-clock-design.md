# 小猪举铁钟

用户已确认 UI 效果图并授权完成 EXE。

Windows 原生 WinForms 应用，奶油白背景、粉色控件、深棕字体。工作状态小猪举哑铃，休息状态小猪盖绿色被子；用矢量绘制连续动画，外观尽量贴近参考图。

专注/短休息/长休息默认为 25/5/15 分钟，可在设置中修改（1–180 分钟）。支持开始、暂停、继续、重置、手动切换。计时结束响铃、提示，并准备下一阶段，等待用户开始；四次专注后准备长休息。暂停停止动画。最小化继续计时，关闭退出。

每日清单支持添加、完成、删除及日期浏览，自动保存。日期变化自动显示当天；历史任务保留。数据存于 LocalApplicationData/PigLiftClock/data.xml，原子替换并保留备份；文件损坏时读取备份并提示。置顶与时长设置保存。

交付单个 EXE、源码和中文说明。使用 Windows 内置 .NET Framework 4 编译器；无需额外运行时下载。验证计时暂停/恢复/到期一次触发、阶段切换、任务持久化/日期隔离、损坏备份恢复，以及真实窗体绘制和控件操作。
